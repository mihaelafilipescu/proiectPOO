# HayDay-Simulator-OOP

A console-based C++ application developed for the Object-Oriented Programming (POO) course, simulating core mechanics of the popular **Hay Day** farming game.

## About the Project
The application models a virtual farm environment where players can manage farming operations, interact with crops and animals, handle inventory, and progress through game mechanics built entirely using object-oriented paradigms.

## Key Features & Architecture
* **Game Entities & Inheritance:** Hierarchical class structures representing various farm items, crops, animals, and inventory assets.
* **Core Simulation Mechanics:**
  * Planting, growing, and harvesting crops.
  * Animal feeding and resource production.
  * Inventory management and trade/economy simulation.
* **Object-Oriented Design:** Implements encapsulation, inheritance, and polymorphism to ensure a clean and modular architecture.
* **Dynamic Memory & Safety:** Proper implementation of constructors, destructors, copy constructors, and operator overloads for efficient data management.
* **Exception Handling:** Robust input and runtime validation ensuring stable execution during gameplay loops.

## Tech Stack
* **Language:** C++
* **Paradigm:** Object-Oriented Programming (OOP)
* **Environment:** GCC / Visual Studio / CLion
